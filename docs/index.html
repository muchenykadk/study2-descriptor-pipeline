Fragment descriptor records

Twelve demolition concrete fragments from a built urban-furniture commission, scanned and characterised into one queryable record each. Every field carries the method that produced it and a data status. Open a fragment for the 3D viewer, per-region surface features, and the derived actions and design implications.

Surface labels are provisional. The classifier does not exceed a null model that answers the two commonest features and looks at nothing. Geometry is computed deterministically and is verified. A rebar_visible negative is absent evidence, not evidence of absence, and must not be read as drilling guidance. See the repository README for the evaluation.
